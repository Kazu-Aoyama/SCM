# SCM
UTokyo-SCMリカレント教育

システムズアプローチで SCM の問題を解く演習のためのツール群。どれもブラウザで開く単体の HTML（インストール不要，データは端末の外へ送らない）。

## 構成（配布フォルダと同じ）

| ファイル | 役割 |
|---|---|
| `20261122_…_演習ファイル索引_v5.html` | 配布ファイルの目次とツールの入口（一番上に置く） |
| `tools/…_システム分析ナビ_v8.html` | ① 読む：例題で SVN・認知マップ・CLD をたどる。自分の問題を文・Excel・draw.io で入れる |
| `tools/…_システム分析ワークベンチ_v21.html` | ② 描く：SVN・認知マップ・CLD を描いて分析する（マトリクス・ループ・仮説の検証） |
| `tools/…_システム分析ラボ_v6.html` | ③ 動かす：CLD を SD にして動かす。ブルウィップ・TOC。自分の時系列で校正・シナリオ比較 |
| `tools/…_SCMミステリー-データブラウザ_v6.html` | ④ 確かめる：実績データを集計し，CLD の矢印をデータで検算する。自社データの取り込み |
| `src/scm-io.js` | 共通モジュール（Excel・CSV の読み書き，ツール間の受け渡し） |
| `src/build.py` | 共通モジュールを各ツールに埋め込み，索引のツール項目（ファイル名・大きさ）を更新する |
| `src/INTEGRATION.md` | ツール間の受け渡しの取り決め |

## ツールのつながり

```
ナビ ──「ワークベンチで描く」──▶ ワークベンチ ──「ラボへ渡す」──▶ ラボ
  └───「ラボで動かす」─────────────────────────────────────▲
ワークベンチ ──「データで確かめる」──▶ データブラウザ ──「ワークベンチへ結果を返す」──▶ ワークベンチ
データブラウザ ──「ラボへ送る」（時系列）──▶ ラボ（⑥データ：実績との比較・校正）
```

同じフォルダにあるツールどうしは，ボタンで相手が開いてデータが届く。届かない環境では受け渡しファイル（`.scm.json`）が保存されるので，相手のツールの「開く」で読み込む。

## 自分の職場のデータで使う

| データ | ツール | 入れ方 |
|---|---|---|
| 部門間の流れ・ヒアリングの矢印・言葉のそろえ方 | ナビ・ワークベンチ | 「テンプレート（Excel）を保存」→ 記入 →「開く」 |
| 需要・計画・稼働・在庫の時系列 | ラボ（⑥データ） | Excel・CSV を落とし，期間の列と値の列を選ぶ |
| 受注・納品・出荷・在庫・生産・設備・調達の明細 | データブラウザ（データ読込） | ERP・Excel の書き出しをそのまま落とし，列を対応づける（対応づけは保存して毎月使える） |

Excel（.xlsx）と CSV（UTF-8／Shift_JIS）を読める。古い .xls は Excel で .xlsx に保存し直す。

## 開発

共通モジュールを直したら：

```bash
python3 src/build.py
```

埋め込みが最新かだけを調べる：

```bash
python3 src/build.py --check
```

ツールの版を上げるときは `git mv` でファイル名を変えてから `build.py` を実行する（ツール間のリンクと索引の項目が新しい名前になる）。
